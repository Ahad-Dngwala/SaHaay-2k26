# SaHaay Stitch Design References

This directory contains the extracted Stitch reference pack for the SaHaay offline-first emergency dispatch platform.

## Directory Structure

- `01_shared_design_system/DESIGN.md`: The canonical design tokens, color palette, typography, component rules, and interaction states.
- `02_citizen_tracking/`: Screen reference (`screen.png`) and HTML mockup (`code.html`) for the Citizen Live Route/Tracking view.
- `03_citizen_sos/`: Screen reference (`screen.png`) and HTML mockup (`code.html`) for the Citizen Dark SOS emergency activation module.
- `04_driver_dispatch/`: Screen reference (`screen.png`) and HTML mockup (`code.html`) for the Ambulance Driver Dispatch view.
- `05_visual_reference_social_ui/`: Supplemental visual composition reference (dark app shell, high-contrast cards).
- `06_visual_reference_dark_explore_ui/`: Supplemental visual composition reference (floating capsule navigation, ambient depth).
