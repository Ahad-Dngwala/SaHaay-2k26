## Benchmark Evidence
- Spatial query latency measured with `npm run bench`:
  - **1,000 ambulances**: $p50 = 4.2\ \mu\text{s}$, $p99 = 0.191\text{ ms}$ at $500\text{ m}$.
  - **10,000 ambulances**: $p50 = 4.3\ \mu\text{s}$, $p99 = 0.026\text{ ms}$ ($0.000026\text{ s}$) at $500\text{ m}$.
  - Target requirement: $< 200\text{ ms}$. **Result: Exceeded by over $7,600\times$**.
  - **Scope Note:** Measures in-process `SpatialGrid.query()` on synthetic Ahmedabad fleet; excludes network transit, database I/O, or cellular transmission.
