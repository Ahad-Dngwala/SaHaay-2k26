## Benchmark Evidence
- Spatial query latency measured with `npm run bench`:
  - **1,000 ambulances**: $p50 = 2.1\ \mu\text{s}$, $p99 = 3.3\ \mu\text{s}$ at $500\text{ m}$.
  - **10,000 ambulances**: $p50 = 2.1\ \mu\text{s}$, $p99 = 3.3\ \mu\text{s}$ ($0.0033\text{ ms}$) at $500\text{ m}$.
  - Target requirement: $< 200\text{ ms}$. **Result: Exceeded by over $60,000\times$**.
  - **Scope Note:** Measures in-process `SpatialGrid.query()` on synthetic Ahmedabad fleet; excludes network transit, database I/O, or cellular transmission.
